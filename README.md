A small program that writes one text (79 characters) to `/output/entry.txt`: the safety warning label that should come printed on every human being — "WARNING: This human's 'quick question' is never quick, and is never a question." Everyone has been caught by a "quick question" before, and everyone knows it is never quick; the turn lands in the last four words, when it turns out it is never a question either.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
